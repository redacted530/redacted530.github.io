# [REDACTED]

A short satirical game in which you black out names in leaked government files and are graded on how little you let through.

## Play

Best in a desktop browser at 1280×800 or larger.

---

## Disclaimer

**[REDACTED] is a work of fiction and a satire.**

Every character, document, agency and event in this game was invented for it. Nothing here is a statement of fact about any real person, living or dead, or any real organisation. The game is inspired by public argument about government secrecy and redaction; that argument is its subject, not its source. Any resemblance between a character's name and a real person's name is coincidental and unintended.

Parts of this game were made with generative AI, including code and written content.

Contains themes of sexual abuse and the trafficking of minors, in written form.
